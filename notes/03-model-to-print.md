# 從模型到成品要幾步？

## 新手會卡在哪？
看完原理和耗材後，不知道「我想印一個東西」實際上要做哪些事、按哪些按鈕。

## 一張圖看懂（#idea）
- 左邊步驟：
  1. 找模型：下載現成的，或自己畫。
  2. 切片：用軟體切成一層一層。
  3. 送去印：把檔案傳給印表機。
  4. 等它印：噴頭一層一層疊上去。
  5. 取下來：等列印板涼了再拿。
- 右邊視覺：新元件 `flow`（五格畫面輪播，像簡報動畫，不放說明文字）
  1. 找模型：螢幕上出現花瓶模型，下載箭頭
  2. 切片：實心的花瓶變淡，換成一條沒有寬度的細線，一層一層來回畫出噴頭要走的路線（W1；作者 2026-11-10 要求「變成線的動作」）
  3. 送去印：檔案從電腦沿虛線飛到印表機（W2：A1 要插 microSD 卡）
  4. 等它印：噴頭一層一層疊出花瓶，旁邊時鐘在轉
  5. 取下來：列印板從紅色（熱）變灰（涼），花瓶才被拿起來（W2）

## 考考你（#quiz，剛好一題）
- 題目：下載好模型之後，下一步要做什麼？
  - ( ) 直接傳給印表機
  - (O) 先用切片軟體切片
  - ( ) 把模型印成圖片
  - 解說：印表機看不懂模型檔，要先切片，變成一層一層的路線。
