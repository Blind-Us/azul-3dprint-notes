# 從模型到成品要幾步？

## 一句話答案（.lesson-lead，40 字內）
五步：找模型、切片、送去印、等它印、取下來。

## 新手會卡在哪？
看完原理和耗材後，不知道「我想印一個東西」實際上要做哪些事、按哪些按鈕。

## 一張圖看懂（#idea）
- 小標題：點一下每一步
- 左邊步驟：
  1. 找模型：下載現成的，或自己畫。
  2. 切片：用軟體切成一層一層。
  3. 送去印：把檔案傳給印表機。
  4. 等它印：噴頭一層一層疊上去。
  5. 取下來：等列印板涼了再拿。
- 右邊視覺：picker（現有元件），五個按鈕對應五步，每個面板：emoji＋標題＋一兩句話
  - 🧩 找模型：模型網站有很多免費檔案（例如 MakerWorld），也可以用 Tinkercad 自己畫。（舉例）
  - 🔪 切片：免費的 Bambu Studio 會把模型切成幾百層，算出噴頭怎麼走。（S0、W1）
  - 📤 送去印：按「列印」把檔案傳給印表機。A1 要先插好 microSD 卡。（W2）
  - ⏳ 等它印：小東西幾十分鐘，大東西好幾個小時。前幾分鐘看一下第一層。（經驗起點）
  - ✂️ 取下來：等列印板完全涼了再拿（W2），再拆掉支撐。

## 重點（#points，3 張卡片）
- 📦｜STL 是什麼？｜最常見的 3D 模型檔，就像照片常用 JPG 一樣。（比喻）
- 🏗️｜支撐是什麼？｜懸在半空的地方要先印「鷹架」撐著，印完再拆掉。（比喻）
- 💻｜軟體要錢嗎？｜不用，Bambu Studio 是免費的切片軟體。（S0）
- 安全提示（callout.warn）：列印中噴頭和列印板都很燙，取件前先等它涼。

## 考考你（#quiz，剛好一題）
- 題目：下載好模型之後，下一步要做什麼？
  - ( ) 直接傳給印表機
  - (O) 先用切片軟體切片
  - ( ) 把模型印成圖片
  - 解說：印表機看不懂模型檔，要先切片，變成一層一層的路線。
