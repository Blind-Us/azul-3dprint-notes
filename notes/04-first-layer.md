# 第一層與附著：列印失敗先查這裡

## 一句話摘要
第一層壞了整件就會壞。依症狀檢查板面、調平與噴頭固定。

## 這篇要解決的問題
印到一半整件脫落、第一層刮板或翹邊時，新手常常直接改溫度和速度。其實要先依症狀判斷是「太低」、「沒黏好」還是「機構鬆動」。

## 學完你會（#goals）
- 依第一層的樣子判斷是太低、太高還是沒黏好
- 正確清潔列印板、選對列印板，冷卻後再取件
- 知道什麼時候該重新調平，什麼時候該檢查噴頭固定
- 認得官方第一層預設值，知道不要先亂調它

## 觀念段落
### 為什麼第一層這麼重要（id: why）
- 第一層失敗，整件列印很可能跟著失敗（W3）
- 0.20mm Standard 第一層預設：高度 0.2 mm、線寬 0.5 mm、速度 50 mm/s、加速度 500 mm/s²（P2 initial_layer_*）
- 紋理 PEI 板溫度：PLA Basic 65 °C、PETG HF 70 °C（P5、P6）

### 列印板：乾淨、選對、冷了再取（id: plate）
- 紋理 PEI 板不用膠水就能印 PLA、PETG、TPU（W2）
- 用溫水加一般肥皂清洗，維持附著力（W2）
- 等列印板完全冷卻再取件（W2）
- 官方不建議在 A1 使用 Bambu 紋理 PEI 板以外的列印板，其他板子對熱床的磁吸力可能比較弱（W2）
- 手指油脂會降低附著：經驗通則

### 第一層太低：噴嘴太靠近（id: too-low）
- 症狀：起皮翹起、隆起、波浪紋；噴嘴幾乎貼著板子刮，擠不太出料（W3）
- 原因 1：沒有做熱床調平，特別是換過列印板之後（W3）
- 原因 2：噴頭位置在列印中改變，例如加熱組件螺絲鬆、卡扣沒扣好，擠出壓力把噴頭往下推（W3）
- 處理：切片時開啟熱床調平；仍有問題再檢查噴頭與加熱組件固定（溫度低於 50 °C、關機後依官方指南操作）；用手輕搖噴頭不應有明顯鬆動（W3）
- G-code Z 偏移（G29.1）只是官方列出的暫時做法；建議範圍：紋理板 −0.02 ~ 0 mm、非紋理板 −0.01 ~ 0.01 mm；第一層太高 → 偏移調小，太低 → 調大；找到根本原因後改回預設（W3）

### 沒黏住、翹邊：先查這三件事（id: adhesion）
- 第一層太高的樣子：線條圓圓的、線與線之間有縫、一刮就掉（經驗通則）
- 1. 板面清潔（W2） 2. 熱床調平（W3） 3. 耗材預設與熱床溫度是否對應（P5、P6）
- 大件高溫材料在 A1 上容易翹曲（W2，見 01）
- 冷風直吹、尖角容易翹：避開風口、底部尖角加小圓角或加 brim（經驗起點）

## 動手做（#practice）
- picker：依症狀選擇（刮板波浪／圓滾有縫／角落翹起／只有某一區不好）→ 可能原因與處理順序

## 列印前檢查清單（#checklist）
- [ ] 列印板用溫水加肥皂洗過，並且擦乾
- [ ] 使用 Bambu 紋理 PEI 板
- [ ] 換過列印板後，這次切片有開啟熱床調平
- [ ] 耗材預設和手上的耗材一致（熱床溫度跟著對）
- [ ] 第一層印的時候在旁邊看完
- [ ] 印完等列印板完全冷卻再取件

## 常見問題（#troubleshoot）
| 症狀 | 可能原因 | 先試什麼 |
|---|---|---|
| 波浪紋、刮板、幾乎沒出料 | 第一層太低 | 開啟熱床調平後重印（W3） |
| 調平了還是太低 | 噴頭或加熱組件鬆動 | 依官方指南檢查固定（W3） |
| 線條圓、有縫、一刮就掉 | 太高或板面髒 | 清洗列印板、重新調平 |
| 角落翹起 | 收縮、冷風、尖角 | 清潔、避開風口、加 brim |
| 只有某一區不好 | 換板後沒重新調平 | 開啟熱床調平 |
| 取件時零件變形 | 板子還熱 | 等完全冷卻（W2） |

## 自我檢查（#quiz）
1. 換了列印板，第一層出現波浪紋、噴嘴好像在刮板子，先做什麼？（O）開啟熱床調平後重印
2. G29.1 Z 偏移是什麼性質的做法？（O）暫時修正，找到原因後改回預設
