# 第一次列印要注意什麼？

## 新手會卡在哪？
機器裝好、模型切好了，第一次按下列印卻失敗：東西黏不住、噴頭撞到東西、線打結。
（作者交辦 2026-11-10：列印板乾淨沒東西、機台放穩、床台和導軌沒有異物；其他可以自己補。AI 補了「順好耗材」和「盯第一層」。）

## 一張圖看懂（#idea）
- 左邊步驟：
  1. 清空列印板：板子上不要有東西，擦乾淨，別用手摸。（W12、W2）
  2. 放穩機器：放在平穩的桌上，列印板會前後跑。（作者經驗；W1：列印板是 Y 軸運動部件）
  3. 看看導軌：列印板和導軌上不能有碎料、工具。（W11）
  4. 順好耗材：線不要打結，線頭要固定好。（W12）
  5. 盯第一層：開印後看幾分鐘，第一層要平平黏住。（經驗起點）
- 右邊視覺：新元件 `precheck`。同一台印表機，一次圈出一個要檢查的地方：
  1. 列印板上的碎料和指紋消失
  2. 印表機底下墊著一塊東西，像蹺蹺板一樣左右翹；東西拿掉後平平放好（作者 2026-11-10 要求）
  3. 導軌上的碎料拿掉，列印板順順地前後跑
  4. 打結的紅線變回順的綠線
  5. 噴頭在列印板上畫出第一層

## 重點（#points，3 張卡片）
- 🧽｜怎麼擦板子？｜用溫水加洗碗精洗，或用酒精擦，擦完就別再摸。（W2、W12）
- 📦｜新機器先推一下｜剛開箱的列印板比較卡，先用手把它推到底再印。（W13）
- 🧊｜印完等它涼｜列印板涼了再拿，東西比較好拔，也不會燙手。（W2）

## 考考你（#quiz，剛好一題）
- 題目：開印前發現列印板上有上次留下的小碎料，要怎麼辦？
  - ( ) 沒關係，直接印
  - (O) 先拿掉，再把板子擦乾淨
  - ( ) 印大一點把它蓋過去
  - 解說：板子上有東西，第一層就黏不好，噴頭還可能撞到它。

## 資料來源（#sources）
- 列印板乾淨、酒精擦、別用手摸；耗材沒有打結：W12
- 溫水和肥皂清洗；完全冷卻再取件：W2
- 導軌異物要清掉：W11
- 新機器先手動把列印板推到最大行程：W13
- 列印板沿 Y 軸前後移動：W1
- 放穩、盯第一層：作者經驗（經驗起點）
