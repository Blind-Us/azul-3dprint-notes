# 3D 列印怎麼印出來？

## 新手會卡在哪？
完全沒看過 3D 印表機的人，不知道東西是怎麼「長」出來的，也不懂為什麼一個小東西要印好幾個小時。

## 一張圖看懂（#idea）
- 左邊步驟：
  1. 送線：齒輪把一捲塑膠線往噴頭裡推。
  2. 融化：噴頭加熱到約 220 °C，塑膠變軟。（W1：PLA 約 210–220 °C）
  3. 畫線：噴嘴擠出細細一條，邊走邊畫出一層。
  4. 疊層：一層畫完就往上一層，重複到完成。（W1 的逐層列印）
- 右邊視覺：print-sim 動畫，畫一個 10 層的小花瓶，動畫同步標出左邊目前的步驟

## 重點（#points，3 張卡片）
- 🧵｜耗材就是塑膠線｜一捲一捲賣，像很粗的釣魚線，有很多顏色和材質。（比喻）
- 📏｜一層非常薄｜常用設定是一層 0.2 mm（W6），大約兩張影印紙疊起來。（比喻）
- ⏱️｜所以要印很久｜10 cm 高的東西，一層 0.2 mm，就要畫 500 層。（100 ÷ 0.2 的計算）

## 考考你（#quiz，剛好一題）
- 題目：3D 印表機是怎麼把東西做出來的？
  - (O) 一層一層往上疊
  - ( ) 把一整塊塑膠削掉
  - ( ) 把塑膠倒進模具裡
  - 解說：這種一層一層加上去的做法叫「積層製造」。家用機最常見的是 FDM，就是這頁的噴頭擠料方式。
