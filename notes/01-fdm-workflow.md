# 從點子到成品：FDM 列印工作流

## 一句話摘要
先看懂整條路：建模、切片、列印、取件到後處理，每一步各自決定成品的什麼。

## 這篇要解決的問題
新手常常一開始就鑽進參數，卻不知道問題出在哪一步。先建立整條流程的地圖。

## 學完你會（#goals）
- 說出 FDM 列印的五個階段，以及每個階段決定成品的哪個特性
- 判斷零件受力時最容易從哪個方向斷
- 列出 Bambu Lab A1 的基本限制：尺寸、噴嘴、材料和環境
- 依照用途，替自己的點子選出起步的材料和方向

## 觀念段落
### FDM 是什麼：一層一層堆出來（id: what-is-fdm）
- 加熱線材、從噴嘴擠出，一層疊一層（W1 的流程：模型 → 切片成 G-code → 準備機器 → 逐層列印）
- 層與層之間的結合最弱 → 受力方向要和列印方向一起想（經驗通則）

### 五個階段，各自決定什麼（id: pipeline）
| 階段 | 在做什麼 | 決定成品的什麼 | 常見的坑 |
|---|---|---|---|
| 建模 | Fusion 360 畫圖，輸出 3MF/STL | 強度方向、懸空、配合尺寸 | 沒留配合間隙 |
| 切片 | Bambu Studio 切層、產生 G-code（W1） | 外觀、強度、時間 | 一次改太多參數 |
| 列印 | 裝料、調平、第一層 | 成功或失敗 | 板面油污 |
| 取件與檢查 | 等板冷卻、量尺寸、試裝（W2） | 尺寸是否可用 | 熱的時候硬拔 |
| 後處理 | 去支撐、打磨 | 最終外觀 | 支撐面很醜 |

### 先認識你的機器：A1 的幾個邊界（id: a1-limits）
- 列印範圍 256 × 256 × 256 mm（W1、P1 printable_area / printable_height）
- 出廠 0.4 mm 不鏽鋼噴嘴；含碳纖、玻纖等硬顆粒的耗材要換硬化鋼噴嘴（W2）
- 適合：PLA、PETG、TPU，以及 PLA／PETG 用的支撐材（W2）
- ABS、ASA、PC、PA 等高溫材料：開放式機身 → 層間強度下降、容易翹曲，官方不建議印大件或高填充；ABS／ASA 會釋放刺激性氣體，要通風（W2）
- 官方不建議替 A1 加裝外罩（W2）
- 建議環境 10–30 °C、濕度 85% 以下（W2）
- 沒有內建儲存，要插 microSD 卡才能送出列印（W2）
- 預設耗材設定是 Bambu PLA Basic @BBL A1（P1 default_filament_profile）

## 動手做（#practice）
- picker：裝飾展示／卡扣配合／耐熱環境／彈性防滑 → 起步材料、列印方向、下一篇要讀哪裡
- PLA 在高溫環境（例如夏天的車內）容易軟化變形：經驗通則

## 列印前檢查清單（#checklist）
- [ ] 模型長寬高都在 256 mm 內，或已經拆件
- [ ] 已決定列印方向，知道受力方向和層的關係
- [ ] 選的耗材符合用途
- [ ] 列印板用溫水加一般肥皂洗過、沒有手指油污（W2）
- [ ] microSD 卡已插入（W2）
- [ ] 預留冷卻時間，等列印板完全冷卻再取件（W2）

## 常見問題（#troubleshoot）
| 症狀 | 可能原因 | 先試什麼 |
|---|---|---|
| 模型放不進列印範圍 | 超過 256 mm | 拆件組合，或縮放 |
| 零件沿層斷開 | 受力剛好把層拉開 | 換列印方向（02） |
| 取件時變形 | 板子還熱 | 等完全冷卻（W2） |
| 大件 ABS／ASA 翹曲 | A1 開放式機身 | 改 PLA／PETG 或縮小（W2） |
| 細節糊、時間太長 | 層高不適合 | 讀 03 |

## 自我檢查（#quiz）
1. FDM 零件通常哪個方向最弱？（O）層與層之間（Z 方向）
2. 想用 A1 印 PLA-CF？（O）先換成硬化鋼噴嘴（W2）
