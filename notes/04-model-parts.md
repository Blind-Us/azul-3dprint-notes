# 模型裡有哪些部分？

## 新手會卡在哪？
第一次打開切片軟體，會看到「牆、填充、支撐、橋接」這些詞，不知道它們在模型的哪裡。
（作者交辦：04 改講「模型總共有哪些部分」，取代原本的「切片是什麼」。）

## 一張圖看懂（#idea）
- 左邊步驟（順序要和右邊按鈕一樣）：
  1. 外牆：最外面那幾圈，像牆壁貼的磁磚，是你看到的外表。（比喻）
  2. 填充：裡面一格一格的，像牆裡的鋼筋水泥，撐起整個模型。（W6、W7）
  3. 支撐：懸空的地方先蓋鷹架撐著，印完拆掉。（W5）
  4. 橋接：兩邊有柱子，中間直接拉線跨過去，像天橋。（W8）
- 右邊視覺：新元件 `parts`（模型剖面圖）。一個「ㄇ 字形加右邊懸空」的剖面：
  外牆是外框、填充是裡面的斜格子、支撐是懸空下面的直線、橋接是兩根柱子中間那一條。
  一次亮一個部分，其他變淡；左邊步驟同步標出。

## 重點（#points，比較表）
| 部分 | 像什麼 | 印完還在嗎 |
|---|---|---|
| 外牆 | 牆壁上的磁磚 | ✅ 就是你看到的外表 |
| 填充 | 牆裡的鋼筋水泥 | ✅ 藏在裡面 |
| 支撐 | 工地鷹架 | ✂️ 印完拆掉 |
| 橋接 | 天橋 | ✅ 留著 |

## 考考你（#quiz，剛好一題）
- 題目：3D 列印的東西，裡面通常長怎樣？
  - ( ) 全部都是實心的
  - (O) 一格一格的填充
  - ( ) 完全空心
  - 解說：裡面用格子撐著，省料又省時間。想要更堅固，就多加幾圈外牆、填得更密。（W6）

## 資料來源（#sources）
- 加大填充密度、牆數可以讓模型更堅固：W6
- 填充有網格、蜂窩等很多種圖案：W7
- 懸空的地方要加支撐，印完要移除：W5
- 橋接是跨過空隙、下面沒有支撐的部分：W8
- 磁磚、鋼筋水泥、鷹架、天橋：比喻（作者 2026-11-10 指定）
